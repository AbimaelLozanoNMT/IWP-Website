# CourseCraft-IWP-Website
CSCI 3021 Internet and Web Programming - Final project website with agentic AI.

**CourseCraft** is a web application that helps college students study more effectively by 
connecting to their Canvas account and turning their course content into personalized 
study material. Students can keep notes organized by course, link those notes to 
assignments, modules, and quizzes, and ask an agentic AI assistant to build a study 
plan or practice questions based on their own notes, slides, and quiz results. The 
application is built with HTML5, CSS3, Java Servlets, JSP, and MySQL on Tomcat, and 
the AI agent runs on the server with the same permissions as the student. The goal is to 
give students a single organized place to study, with timely, relevant help that generic 
study tools can’t provide.
